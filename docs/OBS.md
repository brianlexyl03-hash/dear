# OBS Studio setup

1. Install OBS Studio on Windows.
2. Run the web app and API locally.
3. Add a Browser Source in OBS and use the web app URL.
4. For vertical LIVE output, configure a 1080x1920 canvas and size the source accordingly.
5. Test browser-source audio capture and monitoring to avoid echo/feedback.
6. Test privately before broadcasting. This project has not yet been tested against a real OBS installation.
