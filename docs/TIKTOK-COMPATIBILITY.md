# TikTok LIVE connector compatibility

TikTok's public developer APIs are not assumed to provide a general-purpose LIVE comment feed. Third-party packages such as tiktok-live-connector are unofficial and may break when TikTok changes its web protocols. This repository intentionally does not connect to TikTok yet. The current live co-host implementation is Twitch-only and read-only; it must not be presented as TikTok support.

Before enabling any unofficial adapter, pin and review the exact package version, check account eligibility and TikTok terms, and test a real LIVE session. Record received event IDs (redacted), reconnect behavior, and errors. Confirm the implementation has no outgoing chat-send path. Never store cookies or session tokens in source control or logs.

AI answers are intended for spoken audio only; no text replies should be posted to TikTok chat. Guest admission remains a manual host action.

## Instagram Live

The app does not currently ingest Instagram Live comments or audience events. Meta's APIs and permissions are product- and account-eligibility-dependent; do not substitute an unofficial session-cookie scraper. Implement only against a supported Meta API surface after the app has the required review and permissions.

## Current supported live path

Twitch public chat is read through Twitch IRC over WebSocket. AI replies are generated by the configured server-side model and spoken on the creator device; the app does not post replies back to Twitch chat. This is a real chat listener, not a post scheduler. Test it with a real channel before treating it as production-ready.
